**Chroma Hunt** — увлекательная мобильная AR-игра на **Jetpack Compose**, где реальный мир становится вашей игровой картой! Рулетка выбирает редкий или радужный оттенок, а ваша задача — найти предмет этого цвета вокруг себя через камеру смартфона, навести прицел и поймать его в свою коллекцию.

---

## 🎮 Игровой процесс

```
       [ 🎡 Крутить рулетку ] 
                 │
                 ▼
       [ 🎯 Целевой оттенок: HEX + Имя + Подсказка ]
                 │
                 ▼
       [ 📷 Наведение камеры и прицела-выбирателя ]
                 │
                 ▼
       [ ⚡ Точное совпадение (>75%) & Удержание 1 сек ]
                 │
                 ▼
[ 🎉 Screen Shake + Победный звук + Запись в Color Dex ]
                 │
                 ▼
       [ 🏆 Прогресс квестов и новый спин рулетки! ]
```

1. **Колесо Фортуны**: Крутите неоновую рулетку оттенков с реалистичной физикой вращения, пружинящим указателем и механическими щелчками трещотки. В каталоге собрано 20 уникальных цветов: от классической радуги до *Электрического Циана*, *Космического Ультрафиолета*, *Кислотного Лайма* и *Шоколадного Трюфеля*.
2. **Умный прицел-видоискатель**: Наведите центральную линзу на любой физический объект (чашку, одежду, цветок, экран, книгу). Приложение в реальном времени считывает средний RGB сэмплируемой области.
3. **Алгоритм соответствия цветов**: Точность совпадения рассчитывается по формуле цветового расстояния в пространствах **CIELAB ($\Delta E$)** и **HSV**, что учитывает особенности восприятия человеческого глаза.
4. **Фиксация и Захват**: Когда точность превышает установленный порог (по умолчанию 75%), заполняется круговой индикатор фиксации. При удержании в течение 1 секунды срабатывает эффектная отдача: экран сотрясается (*Screen Shake*), взрывается салют из конфетти, играет победный аккорд, а пойманный цвет навсегда сохраняется в базу данных.
5. **Color Dex (Коллекция)**: Интерактивная энциклопедия всех оттенков с отображением даты поимки, рекордной точности и фильтрами по категориям (Спектр, Неон, Пастель, Природа, Тьма).
6. **Квесты охотника**: Выполняйте задания (*«Первый трофей»*, *«Снайпер оттенков»*, *«Неоновый визионер»*, *«Серия поимок»*) и повышайте свой ранг до *«Грандмастера Спектра»*.

## 🛠 Технологический стек

- **Kotlin 2.2.10** & **Jetpack Compose** (Material Design 3, Dark Cyberpunk Theme).
- **CameraX 1.5.0**:
  - `ImageAnalysis` для считывания цветов на лету с оптимизированной частотой (~20 FPS).
  - `Preview` с аппаратным ускорением в `PreviewView`.
  - Управление фонариком (`CameraControl.enableTorch`) и переключение фронтальной/основной камеры.
- **Room Database 2.7.0 & KSP**:
  - Полное локальное сохранение истории находок (`FoundColorEntity`, SQLite).
  - Реактивные потоки `Flow` через `StateFlow`.
- **Процедурный аудио-синтезатор (AudioTrack PCM)**:
  - Генерация щелчков колеса рулетки, импульсов гидролокатора и торжественных аккордов без сторонних тяжелых аудиофайлов.
- **Вибрация и тактильный отклик**:
  - `Vibrator` / `VibrationEffect` с многоступенчатыми паттернами при фиксации и успехе.
- **Инструменты тестирования**:
  - Встроенный интерактивный сэмплер оттенков (удобно для игры на эмуляторе без физической камеры).
  - **Robolectric 4.16.1** и **JUnit** для быстрого запуска модульных тестов без эмулятора.

## 🚀 Сборка и запуск

### Требования
- **JDK 17** или выше.
- **Android SDK** (API 24+).
- **Gradle 9.3.1** (или AGP 9.1.1).

### Клонирование и локальная сборка
```bash
git clone https://github.com/<username>/<repo>.git
cd <repo>

# Восстановление ключа отладки (если не создан):
base64 -d debug.keystore.base64 > debug.keystore

# Подготовка файла переменных окружения:
cp .env.example .env

# Запуск модульных тестов:
gradle testDebugUnitTest

# Сборка Debug APK:
gradle assembleDebug
```
Собранный файл будет находиться по пути:
```
app/build/outputs/apk/debug/app-debug.apk
```

## 🤖 Автоматическая сборка в GitHub Actions (CI/CD)

В репозитории настроен GitHub Actions Workflow (`.github/workflows/android.yml`).

### Как это работает:
1. При каждом **`git push`** или **Pull Request** в ветки `main` / `master` GitHub Actions автоматически запускает виртуальную машину `ubuntu-latest`.
2. Устанавливается **JDK 17** и **Gradle 9.3.1**.
3. Автоматически восстанавливаются `debug.keystore` и конфигурация `.env`.
4. Запускаются Robolectric и модульные тесты (`gradle testDebugUnitTest`).
5. Собирается отладочный APK (`gradle assembleDebug`).
6. Готовый `.apk` загружается в секцию **Artifacts** запущенного действия под именем **`chromahunt-debug-apk`**.

### Как скачать готовый APK из GitHub:
1. Перейдите во вкладку **Actions** в вашем репозитории на GitHub.
2. Выберите последний успешный запуск рабочего процесса (*Android CI & Build APK*).
3. В самом низу страницы в блоке **Artifacts** нажмите на **`chromahunt-debug-apk`**, чтобы скачать архив с готовым APK-файлом на компьютер или телефон.

## 🔒 Разрешения Android Manifest

- `android.permission.CAMERA`: для работы видоискателя и определения цвета предметов.
- `android.permission.FLASHLIGHT`: для поиска цветов в условиях низкой освещенности.
- `android.permission.VIBRATE`: для тактильного отклика при захвате цели.
